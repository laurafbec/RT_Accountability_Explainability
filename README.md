# Accountability-Explainability Architecture with LLM Agents
This repository contains the code for an accountability and explainability architecture developed for ROS 2-based robots. It leverages Kafka as an event streaming platform to ensure the reliable recording of accountable data, which serves as the foundation for an Agentic RAG-based system that generates natural language explanations.

# Configuration
The `broker1` hostname must resolve to the Kafka server's IP address from the host where the accountable service is launched.

To enable TLS support, self-signed certificates, keystores and truststores for recording service (producer) can be generated by running the script [create-secrets.sh](https://github.com/laurafbec/RT_Accountability_Explainability/blob/main/accountability-docker-solution/secrets/create-secrets.sh).

MongoDB connection URI value must be assigned to the connection.uri property in [MongoSinkConnector.properties](https://github.com/laurafbec/RT_Accountability_Explainability/blob/main/accountability-docker-solution/mongodb-kafka-connect/etc/MongoSinkConnector.properties) from Kafka connect, and in [sink-connect.sh](https://github.com/laurafbec/RT_Accountability_Explainability/blob/main/accountability-docker-solution/kafka/scripts/sink-connect.sh) for the Kafka-MongoDB connector creation.
# Usage
## Event Streaming Components
To launch the Kafka components with TLS support, run:
```
docker-compose -f docker-compose-tls.yml up -d
```
### Recording service
After starting the simulation, the recorder service service can be started with the command
```
ros2 launch rt_recorder_explainer rt_recorder_explainer_srv.launch.py
```
The previous recording service can be started and stopped by running
```
ros2 service call /kafka_producer_srv std_srvs/srv/SetBool data:\ true
ros2 service call /kafka_producer_srv std_srvs/srv/SetBool data:\ false
```
### Explainer
First deployment
```
conda create -n rt_explainer python=3.12.0
conda activate rt_explainer
pip install -r requirements.txt
```
Following deployments
```
conda activate rt_explainer
python3 main.py
```
